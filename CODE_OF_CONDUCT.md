# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be respectful, assume good faith, and keep disagreements about ideas, not
people. Harassment, discrimination, or personal attacks are not tolerated in
issues, PRs, or any other project space.

Report concerns to the maintainer listed in `SECURITY.md`.
